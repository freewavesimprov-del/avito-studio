# Отдельный реестр конкурентов

Инструмент формирует очередь проверки компаний и ИП из агрегатов Авито. Расширение браузера он не изменяет и не использует во время работы. В `--seller-metrics` можно передать как расширенный аналитический CSV, так и обычный `avito-sellers-*.csv` из расширения. CSV версии 1.6.0 уже содержит показатели профиля и проверенные реквизиты; при отсутствии метрик просмотров приоритет определяется реальным числом найденных объявлений без искусственного ранжирования одинаковых нулей.

Проект точной идентификации ИП/ООО по техническим зацепкам, OCR и внешним
источникам описан в `ENTITY_RESOLUTION_DESIGN.md`.

## Запуск

После распаковки архива готовый результат можно открыть без запуска скрипта:

```bash
cd ~/Downloads/competitor-intelligence
open output/research-links.html
open output/competitors.csv
```

Для пересборки положите рядом с папкой свежие `avito-sellers-*.csv` и
`avito-research-*.json`, затем укажите их настоящие имена:

```bash
cd ~/Downloads/competitor-intelligence
python3 build_registry.py \
  --seller-metrics ../avito-sellers-2026-10-18T09-35-36-567Z.csv \
  --research-json ../avito-research-2026-10-18T09-35-34-016Z.json \
  --output-dir output \
  --limit 20
open output/research-links.html
```

Имена файлов после даты будут отличаться. Их можно посмотреть командами
`ls ../avito-sellers-*.csv` и `ls ../avito-research-*.json`.

Результат:

- `output/competitors.csv` — редактируемый реестр и поля для юридических/финансовых данных;
- `output/research-links.html` — локальная очередь со ссылками на поиск, карты, ФНС, агрегаторы и закупки;
- `output/README.md` — краткое состояние проверки.

## Автоматический поиск через Yandex Search API

Прямые поисковые адреса Rusprofile и Checko не используются: они нестабильны и
часто возвращают 404. `enrich_yandex.py` отправляет запросы в Yandex Search API,
включая `site:rusprofile.ru` и `site:checko.ru`, получает реальные индексированные
страницы и ранжирует совпадения.

На macOS дважды нажмите `Запустить поиск Yandex.command`: для первой проверки
оставьте предложенный лимит 3, а после успешного результата запустите все 20.
Либо выполните вручную:

```bash
cd ~/Downloads/competitor-intelligence
python3 enrich_yandex.py \
  --registry output/competitors.csv \
  --output-dir output/yandex-search \
  --limit 20
open output/yandex-search/review.html
```

При обновлении инструмента можно, как и раньше, заменить файлы скриптов в
исходной папке. Папку `output` удалять и заменять не нужно: в ней находятся
ваш реестр, результаты и кэш уже оплаченных поисковых запросов. Скрипт при
каждом запуске заново применяет актуальные правила оценки к сохранённому кэшу.

При первом запуске программа запросит folder ID и API-ключ, после чего сохранит
их в `~/.config/avito-competitor-intelligence/yandex-search.json`. Файл доступен
только текущему пользователю macOS (`chmod 600`); ключ не попадает в CSV, HTML
или поисковый кэш. На следующих запусках вводить доступ заново не нужно.
Удалить сохранённые данные можно командой:

```bash
python3 enrich_yandex.py --forget-credentials
```

Используется тот же тип ключа сервисного аккаунта с областью
`yc.search-api.execute`; в каталоге должен быть подключён Yandex Search API и
назначена роль для веб-поиска.

Файлы автоматического этапа:

- `output/yandex-search/competitors.enriched.csv` — лучшие кандидаты;
- `output/yandex-search/search-results.csv` — все результаты и баллы;
- `output/yandex-search/review.html` — удобная проверка найденных совпадений;
- `output/yandex-search/cache/` — кэш, позволяющий продолжить прерванный запуск.

Строки вроде `3 отзыва` и частные имена без дополнительных признаков
автоматически пропускаются. Автоматическое совпадение остаётся кандидатом до
ручного подтверждения ИНН/ОГРН либо нескольких независимых признаков.

Повторный запуск сохраняет вручную заполненные поля из `competitors.csv`, если `seller_url` не изменился.

## Метод сопоставления

- высокая уверенность: ИНН/ОГРН или реквизиты прямо связаны с профилем/официальным сайтом;
- средняя: совпали минимум три независимых признака — бренд, деловой телефон, домен, география, контактное лицо;
- низкая: совпало только название или имя.

В выводы включаются только соответствия с высокой или средней уверенностью. Для частных исполнителей сохраняются только публичные сведения об их профессиональной деятельности.
