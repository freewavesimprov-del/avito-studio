# Расширение для локального исследования Авито

## Установка в Chrome на Mac

1. Распакуйте архив проекта. Найдите папку **browser-extension**; внутри должен быть manifest.json.
2. В Chrome откройте `chrome://extensions`.
3. Включите **Режим разработчика** справа вверху.
4. Нажмите **Загрузить распакованное расширение** и выберите именно папку **browser-extension**.
5. Через значок пазла закрепите **Авито — локальное исследование услуг**.

Python, установщик .command и отдельный Chromium для этого способа не нужны. Chrome не устанавливает расширения прямо из ZIP: сначала распакуйте. После обновления файлов нажмите «Обновить»/значок перезагрузки у расширения на chrome://extensions. Не удаляйте расширение: удаление стирает локальные данные.

## Первый проход

Откройте расширение → **Запросы**. Уже внесены восемь запросов по инъектированию и регион Москва и область (`moskva_i_mo`). Это единый каталог для Авито и Wordstat. Переключатели справа определяют, где используется каждая фраза. Старые JSON-копии расширения импортируются с обоими переключателями включёнными.

Дождитесь появления карточек. Если идёт проверка сайта, дождитесь её завершения. Прокрутите выдачу, чтобы подгрузились нужные карточки. Нажмите значок расширения → **Сохранить открытую страницу**. Оно запишет карточки, запрос, регион, сортировку, страницу из URL, позицию внутри страницы и время. Если Авито перенаправил запрос в подходящую товарную категорию и убрал параметр `q` из адреса, расширение восстанавливает запрос из поисковой строки или заголовка страницы.

Следующие страницы открывайте кнопками сайта и сохраняйте тем же способом. Повторяйте для остальных запросов. Панель показывает уже сохранённые страницы и сортировки по каждому запросу. Повторное сохранение той же страницы создаёт новое наблюдение с новым временем; количество уникальных объявлений от этого не увеличивается.

### Автоматический сбор страниц выдачи

Во вкладке **Запросы** нажмите **Автоматически собрать страницы**. Для первичного исследования выберите страницы 1–4, сортировку «По умолчанию» и оставьте включённым **Пропускать страницы, которые уже когда-либо сохранялись**. Если первые страницы уже есть, очередь начнётся со страницы 2. Каждая страница открывается в новой видимой вкладке, сохраняется и закрывается.

Если на странице меньше 20 карточек, расширение считает выдачу законченной и пропускает более глубокие страницы этого запроса. При проверке сайта процесс останавливается: завершите её вручную и нажмите **Проверить снова**. Прогресс записывается после каждой страницы.

Во время загрузки строка состояния показывает обратный отсчёт и последнюю причину, по которой страница ещё не принята: не распознана выдача, открыт другой запрос, номер страницы или сортировка. Даже если Chrome перестал отвечать на чтение вкладки, отдельная попытка ограничена четырьмя секундами, общий таймаут продолжает работать, а **Стоп** закрывает рабочую вкладку. Обычная нераспознанная страница после таймаута автоматически закрывается и пропускается.

Проверка сайта и капча распознаются отдельно. По умолчанию рабочая вкладка остаётся открытой 120 секунд: можно пройти проверку, после чего сбор продолжится сам. Если проверка не пройдена, расширение закрывает вкладку, ждёт 300 секунд и один раз открывает эту же страницу заново. После исчерпания повторов страница автоматически пропускается, поэтому вся очередь не зависает. Эти три значения можно изменить перед запуском.

Для повторного дневного снимка установите первую и последнюю страницу равными 1 и отключите пропуск сохранённых страниц. Новый снимок сохраняется отдельным наблюдением с новым временем. Сортировка **По дате** использует параметр Авито `s=104` и хранится отдельно от обычного ранжирования.

Рекомендуемая схема исследования:

- один первичный обход страниц 1–4 по всем запросам;
- оценка количества новых уникальных ID, которое добавила каждая страница;
- ежедневный снимок страницы 1 по главным запросам в течение 7–14 дней;
- более глубокий обход раз в неделю либо после изменения списка запросов;
- подробные карточки собираются отдельной очередью только для новых ID.

Глубина 4 не считается универсально достаточной. После первого обхода решение принимается по фактическому приросту новых объявлений. Глубокий ranked-обход описывает доступный срез выдачи, а повторные снимки страницы 1 — ротацию топа. Эти наблюдения нельзя трактовать как продажи.

## Wordstat и расширение списка запросов

Во вкладке **Wordstat** укажите API-ключ и `folder ID` каталога Yandex Cloud. Расширение использует Wordstat v2 по адресу `searchapi.api.cloud.yandex.net`. Для Москвы и Московской области предзаполнен ID региона `1`; поле можно изменить или указать несколько ID через запятую.

Кнопка **Проверить** выполняет один короткий запрос. **Получить спрос и подсказки** обходит фразы, у которых включён переключатель Wordstat, и сохраняет частотность с найденными связанными фразами. Исходные запросы можно сортировать по спросу. Новые фразы фильтруются по тексту, исключаемым словам, диапазону частотности, типу и породившему их исходному запросу, а сортируются по частотности или алфавиту. «Уточнение» содержит исходную фразу; «похожая» — ассоциация Wordstat, которая чаще требует ручной проверки.

Новые фразы сначала появляются как предложения. Отметьте подходящие и добавьте их в общий каталог; для них Wordstat включён, а Авито выключен до вашего решения. Галочки сохраняются при смене фильтров, а кнопки позволяют выбрать все показанные строки или полностью снять выбор. Так случайная широкая подсказка не увеличит очередь Авито автоматически.

API-ключ и `folder ID` хранятся отдельно в `chrome.storage.local`. Они не входят в полную JSON-копию и CSV. Результаты Wordstat входят в JSON, чтобы спрос можно было анализировать вместе с выдачей Авито. Кнопка **Удалить ключ** удаляет сохранённые реквизиты из профиля Chrome.

## Полные объявления

Во вкладке **Объявления** отображается очередь уникальных ID. По умолчанию видны те, у которых пока есть только краткая карточка выдачи. Нажмите **Открыть**, дождитесь объявления, раскройте описание и нужные разделы, прокрутите галерею. Нажмите значок расширения → **Сохранить открытую страницу**.

Сохраняются распознанные заголовок, цена и текст цены, описание, характеристики, адрес, ссылка на профиль, ссылки на загруженные изображения и текст основного блока, если он найден. UI показывает отсутствующие поля. «Полная карточка сохранена» означает сохранённую страницу объявления, а не гарантию наличия всех полей Авито. Изображения сохраняются как URL, сами файлы фотографий не скачиваются. Номера телефонов, скрытые сведения и данные внутренних API не запрашиваются. Одна и та же карточка не требуется для каждого поискового запроса: связи хранятся через ID.

### Автоматическая очередь карточек

Во вкладке **Объявления** нажмите **Автоматически собрать очередь**. Откроется отдельная вкладка управления. Она берёт только уникальные объявления без подробной карточки. По умолчанию серия состоит из 25 карточек, пауза между ними — 15 секунд, ожидание каждой страницы — до 60 секунд. Допустимый интервал — от 5 секунд; это ограничение частоты, а не способ гарантированно избежать ограничений сайта.

Для каждого объявления расширение создаёт одну видимую вкладку Chrome. Когда карточка распознана и сохранена, вкладка закрывается; старая страница не остаётся открытой во время паузы. Затем создаётся новая вкладка следующего объявления. Не закрывайте вкладку управления до завершения или нажатия **Стоп**.

Закрытое, снятое или удалённое объявление сохраняется со статусом «недоступно» и исключается из будущей очереди. Обычная ошибка или нераспознанная карточка автоматически закрывается и пропускается; она останется в очереди следующего запуска.

Проверка сайта и капча распознаются отдельно. По умолчанию рабочая вкладка остаётся открытой 120 секунд: можно пройти проверку, после чего сбор продолжится сам. Если проверка не пройдена, расширение закрывает вкладку, ждёт 300 секунд и один раз открывает эту же карточку заново. После исчерпания повторов карточка пропускается. Расширение не нажимает элементы проверки и не решает капчу. **Пауза** применяется перед следующей карточкой; текущая загрузка завершает своё ожидание. **Стоп** закрывает рабочую вкладку и завершает серию.

Прогресс сохраняется после каждой карточки в общем локальном хранилище. При новом запуске уже подробные карточки исключаются из очереди. Пропущенные и неудачные карточки останутся в очереди будущего запуска. Сделайте резервную копию JSON до большой серии и после неё.

## Выгрузка

Вкладка **Выгрузка**:
- **Полная копия JSON**: все снимки страниц и распознанные данные, включая исходный текст карточек. Это основной файл для передачи на анализ.
- **Объявления CSV**: одна строка на уникальный ID; при наличии используется последняя подробная карточка. Поля `unavailable` и `unavailable_reason` отмечают закрытые или удалённые объявления.
- **Выдача CSV**: отдельная строка на каждое появление ID в сохранённой выдаче с запросом, страницей, позицией и временем.
- **Исполнители CSV**: группировка по ссылке профиля. Объявления без распознанного профиля не объединяются по имени и не входят в эту таблицу.
- **Восстановить полную JSON-копию**: импортирует ранее выгруженный `avito-research-….json` и полностью заменяет локальные данные после подтверждения. CSV для восстановления не подходит.

CSV сохраняется в UTF-8 с BOM. Неизвестная цена остаётся пустой; единица unspecified означает, что она не определена. Не объединяйте цены разных единиц в одну среднюю. Пометка рекламы определяется по видимому тексту и может быть неполной. Счётчик сайта — исходный текст, не подтверждённое количество конкурентов.

## Где хранятся данные

В локальном хранилище расширения, отдельно от папки проекта и результатов Python-сборщика. Результаты исследования никуда не загружаются. При запуске Wordstat выбранные фразы отправляются непосредственно в API Яндекса. Регулярно выгружайте JSON: удаление расширения или профиля Chrome может уничтожить хранилище. Полную JSON-копию можно восстановить во вкладке **Выгрузка**.

Разрешения: activeTab и scripting — читать открытую страницу; доступ к `avito.ru` — читать автоматически открытые карточки; доступ к `searchapi.api.cloud.yandex.net` — отправлять выбранные фразы в Wordstat; storage и unlimitedStorage — хранить выборку. Доступа к cookies нет. Расширение не снимает ограничений Авито: если сайт не показывает данные, нечего сохранять. Селекторы нужно проверять на вашей текущей разметке; тесты используют локальные HTML-образцы, не подтверждают работу на всех вариантах сайта.
