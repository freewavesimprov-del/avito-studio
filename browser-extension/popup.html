Новые фразы

Подсказки не запускают сбор Авито автоматически. Выберите подходящие фразы, добавьте их и включите канал Авито во вкладке «Запросы».

Автосбор открывается в отдельной вкладке управления. В ручном режиме откройте объявление и сохраните его тем же способом. Выгружаются только доступные в загруженной странице данные.

Очередь строится из уникальных ссылок на профили, найденных в объявлениях. Для каждого продавца сохраняются реквизиты, показатели профиля и доля объявлений, уже попавших в исследование.

JSON содержит все сохранённые страницы и карточки. CSV подходят для Excel. Уникальные объявления связаны с наблюдениями через ID.

Каждая часть остаётся меньше заданного лимита. Для восстановления разделённой копии выберите одновременно все её части. Импорт полностью заменяет локальные данные после подтверждения.

Делайте резервную копию JSON: удаление расширения удаляет его локальное хранилище.
